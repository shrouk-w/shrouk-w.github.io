## AdMob

Once AdMob provides your publisher authorization line, add an `app-ads.txt` file
at the repository root using the exact line from your AdMob account. Do not use
an example or another publisher's ID. The resulting URL must be
https://shrouk-w.github.io/app-ads.txt. Enter the root website URL in the Google
Play developer website field and ask AdMob to verify it.

Keep the policy and Google Play Data safety declarations aligned with actual
SDKs and data processing, especially when enabling production ads.
